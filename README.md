### 1. Biological Vision and Machine Vision

Biological vision is the process where the **eyes receive visual information and the brain processes it through layers of neurons**. The brain converts raw visual information into useful representations such as **edges and contours**.

This inspired deep learning to use **multiple layers of artificial neurons**:

- **Input layer:** Receives raw image/pixel values.
- **Hidden layers:** Automatically learn useful features.
- **Output layer:** Produces the final prediction.

Thus, deep learning transforms raw visual data through **successive layers into increasingly meaningful representations**, similar to the layered processing of visual information.

### 2. Challenges in Training Deep Networks

Training deep networks involves several challenges:

- **Finding optimal weights:** Large networks contain many parameters, making optimization difficult.
- **Choosing architecture:** The correct layers and network topology must be selected.
- **Choosing loss function:** The loss function must properly represent the task.
- **Optimization:** Weights need to be updated effectively to reduce the loss.
- **Learning complex patterns:** Linear models are limited for complex relationships.
